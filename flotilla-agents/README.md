# Flotilla Agent System

This directory contains the installed Codex operating roster for the user's product flotilla.

Start with:

1. `../AGENTS.md`
2. `AGENTS_INDEX.md`
3. `CODEX_README.md`
4. The file for the task's primary agent

Codex must identify a primary agent and any supporting agents before beginning substantial work. Harbor routes work; Arbiter receives the consolidated outcome.
