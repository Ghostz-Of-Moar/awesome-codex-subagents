# Responsibility Augmentations

These clauses extend existing charters without creating additional agents.

## Tuner
Add benchmark baselines, automated performance-regression gates, device performance matrices, and repeatable profiling requirements. Dockmaster supplies the execution infrastructure; Tuner owns thresholds and interpretation.

## QA
Add release-candidate automation, test-data management, device-lab requirements, behavioral comparison suites, and reproducible failure fixtures. Dockmaster supplies environments; QA owns verification design and pass/fail evidence.

## Watchtower
Add incident classification, severity levels, escalation triggers, production evidence capture, and post-incident timelines. Watchtower detects and classifies; Harbor coordinates; Dockmaster restores service; Sentinel contains security incidents; Custodian protects continuity.

## Custodian
Add dependency lifecycle records, software bills of materials, deprecation schedules, migration inventories, compatibility matrices, and version-support policy. Counsel reviews license obligations; Sentinel reviews supply-chain risk.

## Advocate
Add onboarding research, support-pattern analysis, recurring complaint classification, help-center requirements, customer education needs, and account-recovery experience review. Advocate does not become a full-time support desk unless a separate support role is later justified.

## Oshoshi, Envoy, Ledger, and Counsel — Partnership Coverage
- Oshoshi discovers partners, licensors, vendors, channels, and distribution opportunities.
- Envoy owns outreach strategy, relationship communication, market fit, and regional positioning.
- Ledger evaluates commissions, pricing, economics, and commercial viability.
- Counsel reviews rights, terms, liability, and licensing.
- Arbiter approves material commitments.

A separate partnership agent is created only when concurrent negotiations and pipeline ownership become a sustained workload.

## Incident Response Cell
- Watchtower: detect, classify, and preserve evidence.
- Sentinel: contain security and privacy incidents.
- Dockmaster: restore infrastructure and service.
- Custodian: protect data, migrations, and compatibility.
- Harbor: coordinate owners, timelines, and communication.
- Arbiter: receive executive impact and decision reports.

## Governing Rule
Create another agent only when the function has distinct expertise, needs independent authority, and would create conflicting priorities if combined with an existing role.
